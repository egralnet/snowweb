# snowweb 開発履歴（ver 0.0.0.1〜0.0.0.5）

snowweb（スノーウェブ）は、「セキュリティ強化型」をコンセプトにした日本語向けの WordPress テーマです。AI が開発し、使っている皆さんからの報告をもとに修正・更新していきます。

### 開発理念

1. AI がコードを書く、無料の国産ワードプレステーマ
2. デザインが追加されていき、1クリックで好きなデザインに。装飾が崩れにくい仕組み
3. 2026年10月の PHP の脆弱性問題やサイバー攻撃に強いテーマ開発を進めていく
4. プラグイン不要になるくらい最初からプログラムに組み込み、プラグインの更新を気にしなくてよい
5. SEO 歴30年近い管理人による、カテゴリー設計なども工夫した独自の SEO 対策
6. AI に好かれる設計（整理された HTML・構造化データ・パンくずリスト）

ここでは、これまでのアップデート内容をまとめます。

- 必要な環境：WordPress 6.6 以上 / PHP 7.4 以上
- ライセンス：GPL v2 以降
- 配布元：ai-ski.net（最新版は GitHub の egralnet/snowweb でも公開）

## ver 0.0.0.5（2026年11月3日）

### snowweb設定に5つのタブを追加

管理画面の「snowweb設定」で、プラグインを使わずに次の設定ができるようになりました。

**記事**
- パンくずリスト
- 更新日の表示（公開日の翌日以降に更新した記事）
- 文字の大きさの切り替えボタン（標準・大・特大）
- 目次の自動挿入（見出しの数や深さを設定可能）
- シェアボタン（X・Facebook・LINE・はてなブックマーク・リンクのコピー）
  - 外部のスクリプトを読み込まないので、表示が軽く、閲覧者の情報も外部に送りません
- 「この記事を書いた人」
- 関連記事（同じカテゴリーの記事）
- コピー対策（初期はオフ）

**SEO**
- タイトルの区切り文字
- トップページと記事ごとの説明文（メタディスクリプション）
- OGP、X（Twitter）のカード
- 構造化データ（記事・パンくずリスト・サイト情報）
- 検索結果・日付別一覧・2ページ目以降を検索エンジンに載せない設定（noindex）
- 投稿画面に、記事ごとの説明文と noindex の入力欄を追加
- Yoast SEO・Rank Math・SEO SIMPLE PACK などの SEO プラグインが有効なときは、重複を避けるため自動で停止します

**広告**
- AdSense の自動広告
- 広告コードの表示場所：本文の最初、最初の見出し2の前、本文の最後、サイドバー
- ログイン中は広告を表示しない設定（自分でクリックしてしまうのを防止）
- ads.txt の表示
- スクリプトを含む広告コードは、管理者だけが保存できるようにしました（安全対策）

**アクセス解析**
- Google アナリティクス（GA4）
- Google Search Console・Bing の確認コード
- 人気記事の集計とランキング表示（初期はオフ）

**設定の保存**
- 設定をファイル（JSON）に書き出し、読み込みもできます（サイトの引っ越しやバックアップ用）

### 安全対策
- 入力欄ごとに、正しい形の値だけを保存するようにしました（例：GA4 は「G-」で始まる ID のみ）

### 配布・説明書
- 配布用の zip（snowweb.zip）を公開しました。下のアドレスから、いつでも最新版をダウンロードできます
  - https://github.com/egralnet/snowweb/releases/latest/download/snowweb.zip
- イラスト付きの説明書「snowweb つかいかたガイド」（PDF・14ページ）を作りました

## ver 0.0.0.4（2026年11月3日）

### デザインを全面的に作り直し

ai-ski.net のデザインをもとに、全体の見た目を作り直しました。

- **ヘッダー**：大文字のサイト名とキャッチフレーズ、小さめで太字のメニュー
- **記事一覧**：白い箱の2列カード（サムネイル・タイトル・日付）
- **おすすめ記事**：先頭に固定した記事をカードで表示
- **見出し**：「— 新着記事 —」のように左右に線が伸びる形
- **サイドバー**：枠だけの検索、濃い色のカテゴリー、リボン付きの見出し
- **記事本文**：見出し2〜6、表、引用、マーカー、ソースコードの装飾
- **フッター**：濃い色の地に、サイト名とメニュー
- アイキャッチ画像がない記事には、サイト名入りの画像を表示
- カテゴリー・検索結果のページを追加
- 3つのデザイン（標準・コーポレート・やさしい）すべてで、色が正しく切り替わるように

### 不具合の修正
- 記事一覧のタイトルに、本文用の大見出しの装飾が付いてしまう不具合
- サイドバーの検索ボタンの文字が縦に折り返してしまう不具合

### その他
- カラム数の初期値を2カラムに変更
- テーマを更新したとき、選んでいるデザインを自動で当て直すように

## ver 0.0.0.1（2026年11月3日）

### 最初のバージョンを公開
- ブロックテーマ（サイトエディター対応）の土台
- 3つのデザイン：標準（ブログ向け）、コーポレート、やさしい（女性向け）
- 最初から入っているセキュリティ機能
  - WordPress のバージョン番号を隠す
  - セキュリティヘッダー
  - XML-RPC を止める（パスワードの総当たり攻撃の入口を閉じる）
  - ログイン用のユーザー名を調べられないようにする
- **セーフモード**：`wp-config.php` に `define( 'SNOWWEB_SAFE_MODE', true );` を書くと、セキュリティ機能をすべて止められます（ログインできなくなったとき用）
- 更新のたびに自動テストを実行（PHP 7.4〜8.4 での構文チェック、WordPress のコーディング規約、PHP の互換性）

## 不具合・脆弱性の報告について

- **ふつうの不具合**：GitHub の Issues にお寄せください。どのページで、何をしたら、どうなったかと、画面の写真があると助かります。
- **セキュリティの問題（脆弱性）**：悪用を防ぐため、公開の場には書かず、GitHub の「Security」→「Report a vulnerability」から非公開でお知らせください。

※ snowweb は無保証です。更新の前には、必ずサイトのバックアップを取ってください。
