第1章

snowweb（スノーウェブ）ってなに？

ワードプレスは、ホームページを作るための道具です。ワードプレスをお家とすると、テーマはお家の内装や家具のようなものです。テーマを変えると、中身（記事）はそのままで、見た目だけががらっと変わります。

snowweb の3つのとくちょう

1クリックで着せかえ

ブログ向け・会社向け・やさしい雰囲気の3つから選べます。

守りが強い

悪い人にねらわれやすい入口を、最初から閉じています。

設定がひとまとめ

SEO・広告・アクセス解析まで、プラグインなしで設定できます。

AI が作り、みんなの報告で育つテーマです

snowweb は AI（人工知能）が作り、使っている人からの「ここがおかしいよ」という報告をもとに、直しながら新しくしていくテーマです。気になるところがあれば、ぜひ教えてください（13ページ）。

開発理念

AI開発ワードプレステーマ snowweb のコンセプト

snowweb は、次の6つを大切にして作っています。

1AI がコードを書く、無料の国産テーマ

プログラムは AI が書き、日本の利用者に合わせて作っています。無料で使えます。

2デザインが増えていく、1クリックの着せかえ

デザインはこれからも追加していきます。好きなデザインを1クリックで選べて、色や飾りはテーマがまとめて切りかえるので、装飾が崩れにくい仕組みです。

3サイバー攻撃に強いテーマへ

2026年10月に問題になった PHP の脆弱性のような出来事やサイバー攻撃に負けないよう、守りに強いテーマの開発を進めていきます。

4プラグインがいらなくなるくらい、最初から組みこみ

よく使う機能をテーマのプログラムに最初から入れているので、プラグインを減らせます。プラグインの更新や相性を気にする手間が少なくなります。

5SEO 歴30年近い管理人の、独自の SEO 対策

カテゴリーの作り方なども工夫してきた管理人の経験をもとに、検索で見つけてもらうための独自の対策を取り入れています。

6AI に好かれる設計

検索 AI やチャット AI が、記事の内容を正しく読み取りやすい作り（整理された HTML、構造化データ、パンくずリストなど）にしています。

見た目はかんたんに、守りはしっかり、検索にも AI にも強く。それが snowweb のめざすテーマだよ！

第2章

使う前に準備すること

① ワードプレスとサーバーの条件

ワードプレスバージョン 6.6 以上
管理画面の左上の ダッシュボード → 更新 で確認できます。
PHP（ピーエイチピー）バージョン 7.4 以上（8.1 以上がおすすめ）
サーバーの管理画面で確認・変更できます。わからないときは、レンタルサーバーの会社の説明を見てください。

② かならずバックアップをとる

テーマを入れたり新しくしたりする前に、サイトのコピー（バックアップ）をとっておきましょう。

多くのレンタルサーバーには「自動バックアップ」の機能があります。

③ 練習用のサイトがあると安心

本番のサイトとは別に、練習用（検証用）のサイトを用意して、そこで先に試すのがいちばん安全です。

いきなり本番で試すのは、スキーでいきなり上級者コースに行くようなもの。まずは練習コースで！

第3章

テーマを入れる（インストール）

  1. テーマのファイル（zip）をダウンロードする
    配布元の ai-ski.net の snowweb のページからダウンロードします。
    GitHub（github.com/egralnet/snowweb）の Code → Download ZIP からも最新版を入手できます。
  2. 管理画面でアップロードする
    外観 → テーマ → 新しいテーマを追加 → テーマのアップロード と進み、ダウンロードした zip を選んで 今すぐインストール を押します。
  3. 有効化する
    インストールが終わったら 有効化 を押します。これで snowweb に切りかわります。
新しいバージョンに更新するとき

同じ手順で zip をアップロードすると「すでにあります。置きかえますか？」と出るので、アップロードしたもので現在のものを置き換える を押します。設定は消えません。

「snowweb設定」の場所

有効化すると、管理画面の左のメニューに盾（たて）のマークの「snowweb設定」が出てきます。snowweb の設定は、ほとんどここだけで終わります。

全体カラム数（1列・2列）、サイドバーの位置、デザインの着せかえ
記事目次・シェアボタン・関連記事など、記事を読みやすくする機能
SEO検索で見つけてもらうための設定
広告Google アドセンスなどの広告の設定
アクセス解析何人が見に来たかを数えるための設定
セキュリティサイトを守る機能のオン・オフ
設定の保存設定をファイルに保存したり、もどしたりする
変えたら、さいごに青い 「設定を保存」 ボタンをわすれずに！タブごとに保存してね。

第5章

全体：見た目を1クリックで変える

カラム数（列の数）

1カラム

記事だけを真ん中に表示。すっきり読ませたいときに。

2カラム（はじめはこれ）

右か左に「サイドバー」（検索・カテゴリーなど）を表示。

スマートフォンでは、サイドバーは自動で記事の下にならびます。

デザイン（着せかえ）

標準

白黒＋青。ブログ向け。ai-ski.net と同じ雰囲気。

コーポレート

紺色と金色。会社やお店のサイト向け。

やさしい

ピンクとむらさき。角が丸い、やわらかい雰囲気。

ちゅうい

デザインを切りかえると、外観 → エディター → スタイル で自分で変えた色や文字の設定は、上書きされて消えます。

第6章

記事：読みやすくする機能

オンにすると、記事のページに自動で次の部品が入ります。

目次見出しが3つ以上ある記事に、自動で目次を入れます（数は変えられます）。
書いた人ユーザー → プロフィール の「プロフィール情報」に書いた文が出ます。
コピー対策 最初はオフ本文を選んだりコピーしたりしにくくします。完全には防げません。

第7章

SEO・アクセス解析

SEO（エスイーオー）＝ 検索で見つけてもらう工夫

説明文は、検索結果でタイトルの下に出る文です。記事ごとに、投稿画面のいちばん下の snowweb：SEO の欄に書けます。

書かないときは、記事の最初の文が自動で使われます。

OGPX（Twitter）や LINE でシェアされたときに、画像とタイトルがきれいに出るようにします。
構造化データ「これは記事です」「書いた日はこれです」と、Google にわかりやすく伝えます。
noindex「このページは検索結果に出さないで」とお願いする印です。

Yoast SEO などのSEO プラグインを使っている場合は、二重にならないように snowweb の SEO 機能は自動で止まります。

アクセス解析 ＝ 何人来たかを数える

GA4 の測定 IDGoogle アナリティクスの G- ではじまる番号を入れると、計測が始まります。
確認コードGoogle Search Console や Bing に「このサイトは自分のものです」と証明するための文字です。
人気記事の集計 最初はオフ記事ごとに読まれた回数を数え、設定画面の下にランキングを出します。

第8章

広告：広告をのせる

つかい方

  1. 広告の会社（Google アドセンスなど）でもらった広告コードを、広告コードの欄にはりつけます。
  2. 左の絵の①〜④のうち、出したい場所をオンにします。
  3. 設定を保存 を押します。
自動広告

アドセンスの「サイト運営者 ID」（ca-pub-ではじまる番号）を入れて自動広告をオンにすると、場所は Google が自動で決めてくれます。

ログインしている間は、自分の広告をまちがえてクリックしないように広告が出ないようになっています。広告が見えなくても、こわれていないよ！
ads.txtアドセンスで使う「ads.txt」の中身をはりつけると、/ads.txt で表示します。

第9章

セキュリティ：サイトを守る

サイトをお家にたとえると、snowweb は使っていない窓やドアに、最初からカギをかけておくテーマです。

はじめは全部オンになっています。ふつうはそのままで大丈夫です。

バージョン番号を隠す「このサイトは古いワードプレスだ」と、悪い人に知られにくくします。
セキュリティヘッダーほかのサイトの中にこっそり埋めこまれるのを防ぐなど、ブラウザーに「守って」と伝えます。
XML-RPC を止めるパスワードの当てずっぽう攻撃に使われやすい入口を閉じます。
Jetpack や一部のスマホアプリを使うときはオフにしてください。
ユーザー名を隠すログインに使う名前を、外から調べられないようにします。

もしログインできなくなったら（セーフモード）

サーバーにある wp-config.php というファイルに、次の1行を書きたすと、snowweb の守る機能がすべて止まります。

define( 'SNOWWEB_SAFE_MODE', true );

問題が直ったら、この1行は消してください。ファイルの書きかえ方がわからないときは、サーバーの会社のサポートに相談しましょう。

テーマを別のものに変えると、snowweb の守る機能も一緒になくなります。また、テーマだけではすべての攻撃は防げません。ワードプレスやプラグインはいつも最新にして、パスワードは長く、ほかと使い回さないようにしましょう。

第10章

設定の保存と、困ったとき

設定をファイルに保存する

設定の保存 タブの ファイルに書き出す で、今の設定を1つのファイルにできます。引っこしのときは 読み込む でもどせます。

困ったときは

デザインが新しくならない外観 → エディター でテンプレートを自分で変えたことがあると、そちらが優先されます。変えたテンプレートを開き、右上の ⋮ → リセット を押してください。
広告が出ないログイン中は出ません。ログアウトするか、別のブラウザーで見てください。
目次が出ない見出しの数が少ないと出ません。記事 タブの「目次を出す見出しの数」を確認してください。
SEO の欄がないSEO プラグインが有効なときは、snowweb の SEO 機能は止まっています。
ログインできない12ページの「セーフモード」をためしてください。

おかしいところを見つけたら

ふつうの不具合

GitHub の Issues に書いてください。どのページで、何をしたら、どうなったかと、画面の写真があると助かります。

セキュリティの問題

悪用されるおそれがあるので、みんなが見られる場所には書かず、GitHub の Security → Report a vulnerability からこっそり知らせてください。

第11章

ことばの説明（用語集）

ワードプレスホームページやブログを作るための、世界でいちばん使われている道具。
テーマサイトの見た目（デザイン）を決めるもの。着せかえの服のようなもの。
プラグインワードプレスにあとから機能を足す部品。snowweb は、よく使う機能をテーマの中に入れてあるので、プラグインを減らせます。
管理画面ワードプレスの設定や記事を書く画面。サイトのアドレスの後ろに /wp-admin をつけると開けます。
PHPワードプレスを動かしているプログラムのことば。
サイドバー記事の横にある細い列。検索やカテゴリーをならべます。
アイキャッチ画像記事の顔になる画像。一覧やシェアのときに表示されます。
SEOGoogle などの検索で、見つけてもらいやすくする工夫。
OGPSNS でシェアされたときの、画像やタイトルの見え方を決める情報。
GA4Google アナリティクス4。サイトに何人来たかなどを調べる無料の道具。
アドセンスGoogle の広告サービス。サイトに広告をのせて、収入を得られます。
バックアップもしものために、サイトのコピーをとっておくこと。
GitHubプログラムを保管・公開する場所。snowweb の最新版はここにあります。
脆弱性（ぜいじゃくせい）プログラムの弱いところ。悪い人に使われると、サイトが乗っ取られることもあります。
さいごまで読んでくれてありがとう！snowweb は、みんなの声でどんどん良くなっていくテーマです。これからもよろしくね。
