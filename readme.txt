== Changelog ==

= 0.0.0.3 =
* snowweb設定に「全体」タブを追加。1カラム・2カラムの切り替え、サイドバーの位置（右・左）、デザイン（標準・コーポレート・やさしい）の切り替え。
* サイドバー（テンプレートパーツ）を追加。初期の中身は検索・新着記事・カテゴリー。

= 0.0.0.2 =
* 管理画面に「snowweb設定」メニューを追加。
* 「セキュリティ」タブで、各セキュリティ機能を個別にオン・オフできるように。
* セーフモード中は設定画面に注意を表示。

= 0.0.0.1 =
* 最初の版。ブロックテーマの土台、3つのスタイル（標準・コーポレート・やさしい）、基本のセキュリティ機能、セーフモード。
