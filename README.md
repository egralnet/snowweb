# snowweb

セキュリティ強化を目指す、日本語向けの WordPress ブロックテーマです。
配布元：<https://ai-ski.net/>

- バージョン：0.0.0.5
- 必要な環境：WordPress 6.6 以上 / PHP 7.4 以上
- ライセンス：GPL v2 以降

## 開発理念

1. AI がコードを書く、無料の国産ワードプレステーマ
2. デザインが追加されていき、1クリックで好きなデザインに。装飾が崩れにくい仕組み
3. 2026年10月の PHP の脆弱性問題やサイバー攻撃に強いテーマ開発を進めていく
4. プラグイン不要になるくらい最初からプログラムに組み込み、プラグインの更新を気にしなくてよい
5. SEO 歴30年近い管理人による、カテゴリー設計なども工夫した独自の SEO 対策
6. AI に好かれる設計（整理された HTML・構造化データ・パンくずリスト）

## 特徴

- **管理画面の「snowweb設定」で設定がまとまる**
  - 全体：1カラム・2カラム、サイドバーの位置、デザインの切り替え
  - 記事：パンくず、更新日、文字の大きさ、目次、シェア、書いた人、関連記事、コピー対策
  - SEO：説明文、OGP、構造化データ、noindex（SEO プラグインがあれば自動で停止）
  - 広告：AdSense の自動広告、広告の表示場所、ads.txt
  - アクセス解析：GA4、Search Console・Bing の確認コード、人気記事の集計
  - セキュリティ：各機能のオン・オフ
  - 設定の保存：設定の書き出し・読み込み
- **1クリックでデザイン切り替え**：標準（ブログ） / コーポレート / やさしい（女性向け）
  - 「snowweb設定 → 全体」または「外観 → エディター → スタイル」から選べます
- **プラグインを使わないセキュリティ機能**（順次追加）
  - WordPress のバージョン番号を隠す
  - 基本のセキュリティヘッダー
  - XML-RPC の無効化
  - ユーザー名を調べられないようにする（`?author=` と REST API）

## 注意

- このテーマは AI が開発し、利用者からの報告をもとに修正・更新しています。
- テーマを切り替えると、セキュリティ機能も無効になります。
- テーマだけでは、他のプラグインや WordPress 本体・サーバーの脆弱性は防げません。
- 無保証です（GPL の条項に従います）。必ずバックアップを取ってからお使いください。

## 締め出されたとき（セーフモード）

`wp-config.php` に `define( 'SNOWWEB_SAFE_MODE', true );` を追加すると、セキュリティ機能がすべて止まります。
